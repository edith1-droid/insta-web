# Insta Web

A modern landing page for the website brand `www.instaweb.com`.

## Run locally

### Option 1: Open directly
Open `index.html` in your browser.

### Option 2: Use a local web server
```bash
cd insta-web
python3 -m http.server 8000
```
Then open:

http://localhost:8000

## Files
- `index.html` — page structure
- `styles.css` — styling and layout
- `script.js` — small interaction effects

## Project status
This site is ready to use as a static landing page.
